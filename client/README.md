# MERN Task Manager

## Features
- User Authentication
- JWT Authorization
- CRUD Operations
- Search & Filter Tasks
- Task Status Management

## Tech Stack
Frontend:
- React
- Tailwind CSS
- Axios
- React Router

Backend:
- Node.js
- Express.js
- MongoDB
- JWT
- bcryptjs

## Installation

### Backend
npm install
npm run dev

### Frontend
npm install
npm run dev
